# CPC60 MSH：从原始参数到 Ehrenfest 动力学

## 当前结论

两份 CSV 与 Sun、Zhang、Liu 的 JCP 160, 034108 (2024)，DOI 10.1063/5.0185076，表 I 一致。电子能量与耦合取自正文，频率和位移直接读取原始 CSV。构象 3 是主目标；构象 2 同时提供输入核验和后续对照。

本包实现同一 MSH 哈密顿量上的 Ehrenfest 计算，不是 NE-FGR、SQC 或 RI-LSC 的复现。134 的图 7 是构象 3、300 K 的 NE-FGR 结果；不能要求 Ehrenfest 与它严格重合。“exact NE-FGR”也不是完整哈密顿量的非微扰精确传播。

资料已经足够定义目标 MSH 与初态。能否以 HEOM/EH-TEMPO 在长时间上获得收敛结果，需要另行测试，本包不作成本保证。

## 文件

- run_cpc60_msh.py：CSV 解析、表 I 参数、单位换算、核验、运行入口。
- ehrenfest_multistate_multimode.py：已核验的通用 Ehrenfest 传播器。
- data/：两份原始 CSV 的字节内容，仅重命名去除文件名中的 (1)。
- prepared_conf2/：构象 2 的输入核验与原子单位模型 JSON。
- tight_check/：构象 3、300 K、4 条轨迹、10 fs 的实现检查结果、输入 JSON 及容差比较。

少量轨迹不能用于物理论证或宣称采样收敛。图中的 ±2 SEM 只反映各时刻的采样统计误差。

## CSV 列与坐标对应

表头为 j,omega_j/au,Sj_11,Sj_21,Sj_31,Sj_12,...,Sj_34。

Sj_an 中，a 是几何方向 1、2、3，n 是电子态：1=pi-pi*、2=CT1、3=CT2、4=G。

每行一个频率，每个频率对应三个坐标；每个电子态有三列位移。因此有 200 个频率、600 个标量核坐标。电子传播只保留三个激发态；G 只定义核初始热分布中心，Gamma_nG=0。

程序采用 mu=3*j+a（j、a 从 0 开始）；频率数组用 np.repeat(w,3)，位移从 [state,j,a] 展平为 [state,mu]。不能把三方向误当作三个独立电子局域浴。

## 构象 3 参数与核验

势阱最低点能量 epsilon=[0,-0.828,-0.640] eV。

耦合 Gamma12=-0.015、Gamma13=0.0072、Gamma23=-0.029 eV，符号保留。

由原始位移反算重组能：

$$
\lambda_{nm}=\frac12\sum_{j,a}\omega_j^2
(S_j^{(an)}-S_j^{(am)})^2.
$$

| 态对 | CSV 反算 / eV | 表 I / eV |
|---|---:|---:|
| 1–2 | 0.340470209 | 0.340 |
| 1–3 | 0.492363103 | 0.492 |
| 2–3 | 0.040663284 | 0.041 |
| 1–G | 0.149939891 | 0.150 |
| 2–G | 0.909912359 | 0.910 |
| 3–G | 1.134407685 | 1.134 |

六项按三位小数取整后均一致。构象 2 的六项也全部通过。

还在实际热位移尺度附近核对了势阱形式与 G 中心展开形式，构象 3 最大差约 5.6e-17 Hartree。

G 中心展开后的系统对角能量为 [0.149939891,0.081912359,0.494407685] eV。这组数留给后续开放系统实现；Ehrenfest 当前直接使用原始位移势阱和 epsilon，不重复添加位移常数。

## 单位与初态

内部统一为原子单位：

- 表 I 的 eV 除以 27.211386245988 转为 Hartree。
- 频率直接用 CSV 的 omega_j/au，不再乘 2π。
- 1 原子时间=0.024188843265857 fs。
- kBT=3.166811563e-6 × T(K) Hartree。
- hbar=1；质量加权核动能为 sum(P_mu²/2)。

CSV 位移按质量加权原子单位使用，六个重组能的独立核验支持该解释。低频模式位移很大并不意味着数据错误。

初始电子态为 pi-pi*，核在 G 势阱中心采样谐振子热态 Wigner 分布，温度默认 300 K。没有额外阻尼、展宽、频率删减或低频截断。

## 运行方法

要求 Python 3.10 或更新版本，以及 numpy、scipy、matplotlib。进入解压目录后运行。

只核验参数、生成原子单位模型：

    python run_cpc60_msh.py --conf 3 --prepare-only

少量轨迹短时间试算：

    python run_cpc60_msh.py --conf 3 --ntraj 8 --t-end-fs 20

不弹窗：

    python run_cpc60_msh.py --conf 3 --ntraj 8 --t-end-fs 20 --no-show

后续增加到 100 fs，仍需检查积分和采样收敛：

    python run_cpc60_msh.py --conf 3 --ntraj 200 --t-end-fs 100 --no-show

更换为 200 K：

    python run_cpc60_msh.py --conf 3 --temperature-K 200 --prepare-only

入口的 t-end-fs、output-dt-fs、max-step-fs 都以 fs 输入。共同输出间隔不是求解器内部的固定步长。

不要把通用程序的无量纲 t_end=30 直接解释为真实模型的 30 fs；本入口已处理换算。

## 输出

程序生成输入核验 JSON、原子单位模型 JSON、完整 NPZ、四面板 PNG 和计算汇总 JSON。

NPZ 中 times 是原子时间，times_fs 是 fs；energy_drift 与 reorganization 是 Hartree，输入核验报告另给重组能的 eV 数值。

每条轨迹减自己的初始总能量。总能量包括核动能、对角势能和电子耦合能。程序不手工归一化振幅，不丢弃失败样本。

完整轨迹保存在内存中。R/P 两个数组共需约 2*Ntraj*Ntime*600*8 字节，此外还有电子变量及能量数组。长时间和大系综应进一步改为在线统计和少量轨迹抽样保存。

## 已完成的实现检查

构象 3，300 K，4 条轨迹，10 fs：

- 收紧容差 rtol=1e-11、atol=1e-13。
- 最大单轨迹归一化误差约 7.4e-10。
- 最大单轨迹总能量漂移约 2.3e-10 Hartree。
- 与 rtol=1e-9、atol=1e-11 的同样本结果相比，平均密度矩阵元素最大差约 7.9e-8。

这是实现与短时间积分检查，没有检验几百 fs 的误差积累，也没有完成轨迹数收敛。

## 与 EH-TEMPO/HEOM 连接

对 G 中心坐标 q，定义

$$
d_{n\mu}=S_{n\mu}-S_{G\mu},\quad
c_{n\mu}=-\omega_\mu^2d_{n\mu},\quad
E_n=\varepsilon_n+\frac12\sum_\mu\omega_\mu^2d_{n\mu}^2.
$$

再由同一组频率与耦合构造完整量子关联矩阵。核初态成为中心化自由热浴。

保留的是有限无阻尼模式。构象 3 最低频模式周期约 1.33 ns，最高频模式周期约 18.2 fs；不能预先假定浴关联函数在几百 fs 内衰减。134 的 NE-FGR 核记忆时间 0.25 ps 不能直接作为 EH-TEMPO 浴关联函数的记忆截断时间。

目前确认了同一模型能完整构造、Ehrenfest 能运行；长时间全量子收敛与方法间的物理比较，是之后的独立工作。
